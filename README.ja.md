# Media Catalog

日本語 · [English](README.md)

画像・動画・TIFF・PowerPoint・SVG・PDF互換Illustratorファイルをサムネイルで管理するWindowsアプリです。

## はじめに

1. **Python 3.12（64 bit）**を、WindowsのPythonランチャー付きでインストールします。
2. アプリをダウンロード・展開し、`app.py` のあるフォルダを開きます。
3. `setup.bat`、`start.bat` の順に実行します。
4. 「フォルダ登録」で管理したいフォルダを選びます。

動画には **FFmpeg**、PowerPointには **Windows版Microsoft PowerPoint** が必要です。

### Anaconda / Minicondaの場合

`setup.bat` の代わりに、Anaconda Promptでアプリのフォルダへ移動して実行します。

```shell
conda create -n media-catalog python=3.12
conda activate media-catalog
conda install -c conda-forge ffmpeg
python -m pip install -r requirements.txt
python app.py
```

## 基本操作

| したいこと | 操作 |
|---|---|
| 言語を切り替える | 上部の「日本語 / English」を選択。次回起動時も維持されます。 |
| フォルダを見る | 左のツリーで選択。「サブフォルダを含む」も切り替えられます。 |
| ページを確認する | サムネイルにマウスを置きます。TIFF・PPTは先頭20ページまで生成・保存し、タイル表示します。総ページ数は保持します。 |
| 元ファイルを開く | ダブルクリック、または右クリックメニューから開きます。 |
| ファイルを探す | ファイル名・メモ・タグを検索。お気に入り・削除候補・エラー・タイムアウトでも絞り込めます。 |
| メモ・タグを付ける | 右の詳細パネルで編集。タグはカンマ区切りです。 |
| 詳細パネルを調整する | 「詳細パネル」で表示切り替え、境界のドラッグで幅を変更します。 |
| 生成を一時停止する | 「生成を一時停止」。実行中の処理とフォルダ監視は継続します。 |
| 再生成する | 右クリックの「再スキャン・再生成」。自動生成をONにし、一時停止を解除してください。 |
| バックアップする | 「DBバックアップ」で新しいファイルへ保存します。 |
| 終了する | トレイアイコンを右クリックして「終了」。通常、閉じるボタンではトレイに格納します。 |

メモ・タグ・お気に入りは、ファイル切り替え・トレイ格納・終了・バックアップ前に保存します。言語を切り替えても未保存の編集は保持されます。

## クラウドフォルダと元ファイル

**自動生成は初期状態でONです。** Box Driveなどの未キャッシュファイルは、サムネイル生成時にダウンロードされる場合があります。ファイル一覧だけを登録したい場合は、先に自動生成をOFFにしてください。保存済みサムネイルの閲覧では元ファイルを取得しません。

更新確認にはファイルサイズ・更新日時を使います。クラウドクライアントが本体を取得せずにこの情報を返せることが前提です。別PCの変更は、このPCへ同期された後に検出します。

アプリは元ファイルを変更・削除しません。見つからなくなったファイルは削除候補として確認できます。登録解除・カタログからの削除では、関連するメモ・タグ・サムネイルも削除されます。元ファイルを外部アプリで開いた場合は、そちらで編集・保存できます。

## 取り込み・検索

メモ・タグの持ち運びは「設定・管理」→「メモ・タグの取り込み」から、別PCの「DBバックアップ」で保存したDBを選びます。パスが違う場合は対応する元・先フォルダを指定し、「差分を確認」で内容を確認してください。タグは重複を除いて統合し、メモ競合は行ごとに選択できます。適用前のDBはデータフォルダ内の `backups` に自動保存されます。元ファイル・取り込み元DB・お気に入り・サムネイルは変更しません。

検索はスペース区切りでAND、`"語句"`でフレーズ、`-語句`で除外できます。`name:`・`memo:`・`tag:`・`path:`・`meta:`・`ext:`・`type:`で対象を指定できます（例：`細胞 tag:実験 -失敗 ext:tif`）。形式・並べ替えは検索欄の右、生成設定は「設定・管理」から操作します。`Ctrl+F`で検索欄へ移動します。

## 困ったとき

- **SVG・Illustrator：** SVGとPDF互換AIに対応します。AIは保存済みPDF部分から先頭20ページまで表示し、Illustratorやリンク先は開きません。PDF互換でないAI・旧形式AIには非対応です。リンク切れや保存時に欠けた画像は復元できません。外部リンク付きSVGはスキップします。埋め込み画像を使ってください。特殊効果やフォントは元アプリと異なる場合があります。
- **顕微鏡TIFF：** 16bit整数・浮動小数点の画像は、ページごとに明るさを自動調整してプレビューします。定量評価用ではなく、元ファイルは変更しません。
- **パスワード付きPPT：** 暗号化が確認できた場合はスキップします。判定できない形式は生成を試します（パスワード入力が出る可能性があります）。0バイトの画像・PPTはエラーにせず、空ファイルとして登録します。
- **FFmpegが見つからない：** アプリを実行するConda環境で `conda install -c conda-forge ffmpeg` を実行し、再起動して再生成してください。別途導入する場合はPATHへ追加するか、`MEDIA_CATALOG_FFMPEG` に実行ファイルのパスを指定できます。
- **大きい画像：** 初期上限は1ページ **300メガピクセル** です。十分なメモリも必要です。必要なら起動前に `MEDIA_CATALOG_MAX_IMAGE_MP` を設定してください（単位：メガピクセル）。
- **タイムアウト：** 初期設定は30分です。遅いダウンロードでは延長してから再試行してください。
- **バックアップ・復元：** 起動中はアプリ内のバックアップ機能を使います。元ファイルはバックアップに含みません。復元は完全終了後に現在のデータフォルダを退避し、バックアップを `catalog.sqlite3` として配置してください。古い `-wal`・`-shm` は混在させないでください。
- **保存場所：** `%LOCALAPPDATA%` 配下のユーザー別MediaCatalogフォルダです。アプリを更新してもカタログは引き継がれます。

Windows標準ダイアログや外部アプリ由来のエラーは、OS側の言語で表示される場合があります。Windows・Box Drive・PowerPointの実機動作は、配布元環境では未検証です。
